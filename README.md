# 📖 Guia de Leitura da Obra de J.R.R. Tolkien

Um site simples e elegante criado para guiar novos leitores pela rica mitologia da Terra-média e as histórias de Arda.

🔗 **Acesse o site:** [https://karolmalazartes.github.io/guia-tolkien/](https://karolmalazartes.github.io/guia-tolkien/)

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do conteúdo.
* **CSS3:** Estilização medieval/Terra-média com CSS Grid, Flexbox e Google Fonts (*Cinzel* e *Lora*).
* **GitHub Pages:** Hospedagem estática e deploy automatizado.
